# Font Awesome Free 6.5.2 — vendorizado localmente

Pacote `@fortawesome/fontawesome-free` versão 6.5.2. Os arquivos são servidos pelo próprio GitHub Pages da Intranet para que os ícones não dependam de um CDN de terceiros sujeito à prevenção de rastreamento do navegador.

A folha `all.min.css` teve somente os caminhos de webfonts ajustados para arquivos irmãos (`./fa-*.woff2` e `./fa-*.ttf`). Consulte `LICENSE.txt` para as licenças do pacote.
